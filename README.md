# ⌨️ DennisRodtype

Веб-приложение для тренировки скорости печати на английском языке.

## 🚀 Функциональность

- Генерация случайного текста для набора
- Посимвольная проверка ввода в реальном времени
- Подсветка:
  - ✅ правильных символов
  - ❌ ошибок
  - текущей позиции курсора
- Поддержка Backspace (исправление ошибок)
- Таймер (30 и 60 секунд)
- Подсчет:
  - WPM (слов в минуту)
  - Accuracy (точность)
- Блокировка ввода после окончания времени
- Сохранение результата в `localStorage`

---

### 📌 Генерация текста
Текст разбивается на символы и оборачивается в `<span>`, чтобы отслеживать каждый ввод:

```js
phrases[phraseIndex].split("").forEach((char) => {
    const spanChar = document.createElement("span");
    spanChar.classList.add("char");
    spanChar.innerText = char;
});
